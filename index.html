Pencetak FP-10

Bila hidup, SAVE turut mencetak: dalam MODE 1, INV GOTO (SAVE) EXE mencetak memori; dalam MODE 3 ia mencetak senarai program. INV GOTO INV EXE mencetak paparan semasa.


    

  






  
Fail FA-2

  

    
Antara muka kaset FA-2 disimpan dalam pelayar ini. SAVE = INV GOTO, LOAD = INV GSB, diikuti nombor fail (0–999) dan EXE. MODE 1 menyimpan memori (.df); MODE 3 menyimpan program (.pf), atau program + memori dengan INV EXE (.af).

    
    
    
    Import
    
    
    
    
    
    
    
    
    Status kalkulator
    
    
    Program dan memori disimpan automatik dalam pelayar ini dan dipulihkan bila halaman dibuka semula.
    
    
    
  
    

    


    
  
    Cara guna
    
  
    
    
    Kekunci bertulisan emas di atas kekunci ialah fungsi INV. Huruf merah ialah aksara mod ALPHA (INV MODE).
    
    
    Mod (MODE + nombor)
    
    
    
      
    KekunciModKegunaan
    
      
    1RUNKiraan biasa dan menjalankan program
    
      
    2WRTMenulis program
    
      
    3PCLMemadam program (AC), SAVE/LOAD program
    
      
    4 · 5 · 6DEG · RAD · GRAUnit sudut untuk trigonometri
    
      
    . nnDEF MBilangan daftar memori (10–100); . . tunjuk tetapan
    
    
    
    
    Menulis dan menjalankan program
    
    
    MODE 2, pilih P0–P4 (atau INV untuk P5–P9), tekan langkah-langkahnya, kemudian MODE 1. Tekan P0 untuk menjalankan. HLT berhenti untuk input; masukkan nombor dan tekan EXE untuk sambung. Dalam WRT, BST/FST bergerak antara langkah dan C memadam satu langkah.
    
    
    Contoh x² + 1: MODE 2 · P0 · HLT · INV MR (x²) · + · 1 · = · MODE 1. Kemudian P0 · 3 · EXE → 10.
    
    
    Memori
    
    
    Min, MR, M+, M−, X↔M diikuti dua digit (00–19). EXP selepasnya memilih daftar F. Statistik menggunakan M07 (Σx²), M08 (Σx) dan M09 (n).
    
    
    Papan kekunci komputer
    
    
    Digit, + − * / . ( ), Enter = EXE, = , Backspace = C, Esc = AC, i = INV, m = MODE.
    
    
    Diagnostik
    
    
    Tiada ralat direkod.
